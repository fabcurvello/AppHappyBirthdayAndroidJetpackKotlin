# App Happy Birthday (Jetpack Compose)

> Repositório didático: exercício prático de Android nativo com **Kotlin**, desenvolvido e aplicado em sala de aula pelo Prof. Fabricio Curvello.

## Sobre o projeto

Cartão de aniversário digital feito com **Jetpack Compose**: uma imagem de fundo com mensagem de parabéns e a assinatura de quem envia.

## Contexto acadêmico

Exercício aplicado em sala de aula, usado como prática guiada com os alunos.

## O que o app faz

- Imagem de fundo com transparência (`alpha`) e corte para preencher a tela (`ContentScale.Crop`).
- Mensagem principal em destaque e assinatura alinhada à direita.
- Textos guardados em `strings.xml`.
- *Preview* configurado para ver o layout direto no Android Studio.

## Conceitos trabalhados em aula

- Funções `@Composable`
- Layouts com `Box` e `Column`
- `Text`, `Image` e `painterResource`
- `Modifier` (padding, alinhamento, tamanho)
- `@Preview` e temas do Material 3

## Tecnologias

- **Kotlin**
- **Android SDK** (Android Studio)
- **Gradle**
- Jetpack Compose
- Material 3
- `minSdk 28` / `compileSdk 34`

## Como executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/fabcurvello/AppHappyBirthdayAndroidJetpackKotlin.git
   ```
2. Abra a pasta no **Android Studio** e aguarde a sincronização do Gradle.
3. Execute em um emulador ou dispositivo físico com Android compatível com a API 28 ou superior.
